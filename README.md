# EventPulse API

EventPulse is a backend API for managing events, users, registrations, and announcements. It provides authentication, event management, event registration, real-time announcements using Socket.io, API documentation with Swagger, and automated testing.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.io
- JWT
- bcrypt
- Jest
- Supertest
- Swagger / OpenAPI
- Vercel

## Features

- User registration and login
- JWT authentication
- Role-based authorization
- Event CRUD operations
- Event filtering, searching, pagination, and sorting
- Event registrations and cancellation
- Event capacity management
- Announcements
- Real-time Socket.io notifications
- Swagger API documentation
- Automated Jest and Supertest tests
